# Makmal Digital Sains Tahun 4 — Bahan

## Kandungan
- `index.html`: satu halaman interaktif yang serasi dengan GitHub Pages.
- Tab Simulator: penerokaan sumber asas dan sifat bahan + 3 misi (9 markah).
- Tab Kuiz Bergambar: 21 soalan ABCD (21 markah).
- Tab Pemerhatian: 5 soalan objektif (5 markah) + 3 jawapan bertulis (15 markah).
- Tab Slip Pencapaian: jumlah 50 markah, peratus, gred A–F, komen guru dan cetak/Simpan PDF.

## Cara menerbitkan di GitHub Pages
1. Muat naik `index.html` ke root repositori GitHub.
2. Buka **Settings → Pages**.
3. Pilih **Deploy from a branch**, pilih `main` dan folder `/ (root)`, kemudian **Save**.
4. Buka URL GitHub Pages yang dipaparkan.

Semua fungsi berjalan di pelayar; tiada pangkalan data atau pelayan diperlukan. Sistem markah bertulis menggunakan kata kunci sebagai cadangan automatik dan guru perlu menyemak jawapan murid.
